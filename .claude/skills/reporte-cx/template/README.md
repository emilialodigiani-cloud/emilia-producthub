# Template del reporte CX

Diseño de referencia del one-pager (dos pestañas: KPIs y Transparencia de la base). Los valores entre corchetes son placeholders.

- `reporte-cx.dc.html`: fuente del diseño (formato Design Component, se abre en el canvas de diseño de Claude).
- `canvas.json`: índice del canvas.

Al generar el reporte, `SKILL.md` define qué se calcula; este template define cómo se muestra. Para un HTML final, reemplazá los placeholders con los datos calculados.
